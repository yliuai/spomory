# 隐私政策 / 数据处理说明（草案，Epic 10.4）

> MVP 对外发布前的必备文档草案。内容严格对齐 Epic 7/8/10 当前**实际实现**
> 的能力——不承诺代码里还没有的东西。云端服务尚处于骨架阶段（Epic 8.2 的
> 云端存储后端尚未实现），本草案里凡涉及云端的条款都标注为"计划中"，
> 正式上线云端服务前需要重新审阅。

## 1. 我们收集什么

- **本地模式**（当前默认）：你导入/输入的文本、由此抽取出的实体和关系，
  连同来源溯源信息（哪段原文、什么时候），存储在你本机的 SQLite 文件里，
  不会自动上传到任何服务器。
- **云端模式**（计划中，Epic 8.2 尚未实现）：注册邮箱、API Key 的哈希值
  （明文 Key 只在生成时展示一次，此后我们自己也拿不到，见 Epic 10.2）、
  你的记忆图谱数据、基础调用日志（时间戳 + 调用了哪个接口，见 Epic 9.3/
  10.3）。

## 2. 我们不收集什么

- 我们不要求你提供除邮箱外的个人身份信息才能使用本地模式。
- 抽取三元组所需的 LLM 调用会把你的文本发送给你自己配置的 LLM 供应商
  （OpenAI、DeepSeek 等，由你通过环境变量指定）——这是调用第三方 API
  的必然结果，你的文本会经过该供应商，我们的服务本身不额外留存这份
  请求内容。

## 3. 数据加密

云端持久化的数据（计划中）会在存储层加密（Epic 10.1，`LocalGraphStore`
已支持可选的 Fernet 字段级加密，云端后端接入时复用同一机制）；加密密钥
不与数据库放在一起。API Key 只存哈希值，泄露数据库也不会泄露可用的 Key
（Epic 10.2）。

## 4. 你的权利：导出与删除

- **随时完整导出**：你可以随时导出你的完整记忆图谱（实体、关系、时间戳、
  来源），格式详见 [`export_format.md`](export_format.md)。这是免费层的
  一部分，不是付费功能。
- **随时彻底删除**：删除操作是物理删除，不是标记删除——我们能提供删除
  前后的记录数对比。每次删除会被记录进一个独立的审计日志（时间、范围），
  但被删除的数据本身不会被这份日志保留。

## 5. 数据保留与第三方共享

- 本地模式下，数据完全由你自己保管，我们无法访问。
- 云端模式（计划中）：除了你主动配置的 LLM/Embedding 供应商（用于抽取和
  检索），我们不会把你的记忆数据出售或共享给其他第三方。

## 6. 我们不做的合规声明

我们不宣称本产品"符合 GDPR"或"受特定法规强制保护"——导出和删除能力是
我们主动选择的产品原则，是领先于监管趋势的设计，而不是现成的合规红利
（欧盟 GDPR 第 20 条数据可携权目前不清晰覆盖 AI 推断生成的个人画像/记忆，
这恰恰是我们认为最应该主动覆盖的部分）。
